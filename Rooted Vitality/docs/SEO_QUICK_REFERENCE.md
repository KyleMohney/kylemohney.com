## SEO Checklist

When adding a new article, verify:

- [ ] Title: 50-60 characters, includes keyword + brand
- [ ] Description: 155-160 characters, compelling, unique
- [ ] Keywords: 6-9 terms, naturally incorporated
- [ ] Author: "Rooted Vitality"
- [ ] OG Title: Same as page title
- [ ] OG Description: Same as meta description
- [ ] OG Type: "article"
- [ ] Article Date: YYYY-MM-DD format (2025-10-28)
- [ ] Article Section: Relevant category
- [ ] Canonical: Points to correct URL on rootedvitality.com
- [ ] Mobile viewport: Included
- [ ] Charset: UTF-8 declared

## Title Tag Formula

```
[Page Topic] | Rooted Vitality
```

**Examples:**
- What Makes Holistic Medicine Different | Rooted Vitality
- Healing Plants for Your Home | Rooted Vitality
- Finding the Right Practitioner | Rooted Vitality

**Length:** 50-60 characters (optimal for Google)

## Description Tag Tips

- 155-160 characters (fits in Google search results)
- Include primary keyword naturally (near beginning)
- Compelling, encourages clicking
- Unique for each page
- Action-oriented language

**Examples:**
- "Discover what makes holistic medicine different. Learn how holistic practitioners view health, wellness, and the connection between mind, body, and spirit."
- "Explore healing plants to keep in your home. Learn about common plants with wellness properties, including garlic, ginger, aloe, and more for holistic health."

## Keyword Strategy

**For Patient Articles:**
- Mix primary + secondary keywords
- Include long-tail phrases (3-4 words)
- Focus on patient problems/questions
- Natural language, not forced
- 6-9 keywords per page

**Example:** "holistic medicine, alternative medicine, wellness, integrative health, holistic health, mind-body connection"

**Avoid:**
- Keyword stuffing
- Repeating same word 10+ times
- Unrelated keywords
- Competitor brand names

## Open Graph for Social Sharing

**What it does:** Controls how your page appears when shared on Facebook, LinkedIn, Twitter, etc.

**Key tags:**
- `og:title` - Headline when shared
- `og:description` - Preview text
- `og:type` - "article" or "website"
- `og:image` - (optional) preview image

**Result when shared:**
```
📰 Page Title | Rooted Vitality
Brief description text that appears as preview...
rootedvitality.com
```

## Canonical URL Format

```html
<link rel="canonical" href="https://rootedvitality.com/articles/[slug].html">
```

**Purpose:** Tells Google which version is "official" to avoid duplicate content penalties

**Examples:**
- index.html: `https://rootedvitality.com/`
- Article: `https://rootedvitality.com/articles/holistic-medicine-explained.html`

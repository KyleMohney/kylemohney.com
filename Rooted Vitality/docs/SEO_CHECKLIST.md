## SEO Optimization Tips

### For Future Content
- Keep titles between 50-60 characters
- Keep descriptions between 155-160 characters
- Target 1-2 primary keywords per page
- Use long-tail keywords (3-4 word phrases)
- Include keyword in first 100 words
- Use descriptive heading hierarchy
- Write for humans first, search engines second

### Content Strategy
- Focus on patient education
- Answer common questions
- Provide actionable information
- Build authority in wellness niche
- Link internally between related articles
- Keep content updated

## Verification Commands

### Check meta tags in browser
1. Open page in Chrome
2. Right-click > View Page Source
3. Search for "meta name" to find all meta tags
4. Verify description matches intent

### Validate HTML
1. Visit validator.w3.org
2. Paste URL or HTML
3. Check for errors/warnings
4. Ensure semantic structure

### Test Mobile Friendliness
1. Visit Google Mobile-Friendly Test
2. Enter URL
3. Verify passes mobile test
4. Check viewport configuration

## Metadata Included on Every Page

### Basic Meta Tags
```html
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

### Title & Description
```html
<title>[Page Title] | Rooted Vitality</title>
<meta name="description" content="[150-160 character description]">
```

### Keywords & Author
```html
<meta name="keywords" content="[keyword1, keyword2, keyword3...]">
<meta name="author" content="Rooted Vitality">
```

### Open Graph (Social Sharing)
```html
<meta name="og:title" content="[Page Title] | Rooted Vitality">
<meta name="og:description" content="[Description text]">
<meta name="og:type" content="article|website">
```

### Article-Specific Metadata
```html
<meta name="article:published_time" content="2025-10-28">
<meta name="article:author" content="Rooted Vitality">
<meta name="article:section" content="[Category]">
```

### Canonical Link (Prevents Duplicates)
```html
<link rel="canonical" href="https://rootedvitality.com/articles/[page].html">
```

## SEO Best Practices Implemented

✅ **Titles**: 28-50 characters, includes brand, contains primary keyword

✅ **Descriptions**: 130-160 characters, compelling, unique per page

✅ **Keywords**: 6-9 terms per page, naturally incorporated, no stuffing

✅ **Structure**: Proper HTML hierarchy, semantic markup, clean code

✅ **Mobile**: Viewport configured, responsive design, touch-friendly

✅ **Performance**: Single 10.2KB stylesheet, minimal file sizes, fast loading

✅ **Social**: Open Graph tags for all platforms (Facebook, LinkedIn, etc.)

✅ **Canonicals**: All URLs point to main domain, prevents indexing issues

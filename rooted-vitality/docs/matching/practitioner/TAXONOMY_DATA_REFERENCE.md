## Database Insert Format

Each category will be inserted as:

```sql
INSERT INTO holistic_health_taxonomy (
  category_id, name, icon, credential_level, credential_description, display_order
) VALUES (
  'acupuncture', 
  'Acupuncture & TCM', 
  '🧬', 
  'license', 
  '🔴 License Required', 
  1
);
```

Each subcategory will be inserted as:

```sql
INSERT INTO taxonomy_subcategories (
  taxonomy_id, name, display_order
) VALUES (
  (SELECT id FROM holistic_health_taxonomy WHERE category_id = 'acupuncture'),
  'Pain Management',
  1
);
```

## Usage in Match Settings

When a practitioner uses the match-settings page:

1. They see all 22 categories in dropdown
2. They search and select (e.g., "Acupuncture & TCM")
3. They see the 20 subcategories for that category
4. They check specific services (e.g., "Pain Management", "Fertility Support")
5. Those selections are saved to `practitioner_selected_services` table
6. When clients search, they only see practitioners who have selected relevant services

## Why This Structure

✅ **Prevents Massage Therapy** - Not in our 22 categories  
✅ **Specific & Professional** - 15-20 services per category  
✅ **Scalable** - Easy to add new categories/services later  
✅ **Searchable** - Clients can find exact match  
✅ **Auditable** - Track what practitioners offer  
✅ **Queryable** - Analytics on service popularity  

---

## File Reference

This data is:
- Defined in: `/data/practitioner-categories.json`
- Loaded by: `loadTaxonomy()` in match-settings.html
- Stored in: `holistic_health_taxonomy` + `taxonomy_subcategories` tables
- Queried by: `practitioner_selected_services` table

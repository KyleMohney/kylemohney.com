// === CARD STRUCTURE ===

Each prompt card contains:
- Tier badge (top-left)
- Complexity dots (top-right)
- Prompt title (bold, 18px)
- 2-line description (14px, muted)
- Tag pills (small, rounded)
- Action buttons: [PREVIEW] [COPY] [CUSTOMIZE]

// === DATA STRUCTURE ===

JSON format with required fields:
- id: unique identifier
- title: prompt name
- tier: strategic/operational/financial/rd/technical
- complexity: 1-3 (dots)
- description: 2-sentence max
- prompt: full template text
- variables: array of customizable elements
- tags: array for filtering
- use_cases: array of applications

// === INTERACTION PATTERNS ===

Search Functionality:
- Real-time filtering by title, description, tags
- Category buttons toggle active state
- Results counter shows filtered total

Modal Behavior:
- Preview opens full prompt with variables highlighted
- Copy button provides clipboard functionality with success toast
- Customize option allows variable editing before copy
